# AI学习诊断 - Windows 桌面端

基于 Electron 构建的 Windows 桌面客户端，提供与网页版一致的学习体验。

## 功能特性

- 🖥️ **独立桌面应用** - 无需浏览器，直接启动使用
- 🔔 **系统通知** - 学习提醒、作业通知实时推送
- 📐 **自定义缩放** - 支持页面放大缩小，保护视力
- 🔒 **安全沙箱** - 上下文隔离，保障数据安全
- 💾 **数据同步** - 与网页版数据完全同步
- 🎯 **单例运行** - 防止多开
- 📦 **两种安装包** - 安装版 + 便携版

## 系统要求

- Windows 10 或更高版本（64位）
- 至少 2GB 内存
- 至少 300MB 可用磁盘空间
- 稳定的网络连接

## 快速开始

### 开发环境运行

```bash
# 安装依赖
cd desktop
npm install

# 启动开发模式
npm start
```

### 打包安装包

```bash
# 打包 Windows 安装版 + 便携版
npm run build:win64

# 输出位置: desktop/dist/
# - AI学习诊断 Setup 1.0.0.exe  (NSIS安装包)
# - AI学习诊断-Portable-1.0.0.exe (便携版，免安装)
```

## 配置说明

修改 `main.js` 中的 `APP_URL` 变量以指向你的服务器地址：

```javascript
const APP_URL = 'https://your-domain.com/';
```

## 安装包类型

| 类型 | 文件 | 说明 |
|------|------|------|
| NSIS安装版 | AI学习诊断 Setup x.x.x.exe | 标准安装程序，支持自定义安装路径、桌面快捷方式 |

## 常见问题

**Q: 安装时提示"未知发布者"怎么办？**
A: 点击"更多信息" → "仍要运行"即可。这是因为代码签名证书需要单独购买。

**Q: 便携版启动慢？**
A: 首次启动需要解压临时文件，之后启动会快很多。

**Q: 数据和网页版同步吗？**
A: 完全同步。桌面端本质上是一个专用浏览器，数据存储在服务器上。

**Q: 如何升级？**
A: 安装版会自动检测更新（需实现自动更新模块）；便携版需手动下载新版本替换。
