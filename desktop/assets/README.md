# 图标资源说明

本目录存放应用图标资源。

## 需要准备的文件

### 必需文件

| 文件名 | 格式 | 推荐尺寸 | 用途 |
|--------|------|----------|------|
| `icon.ico` | ICO | 256x256 (含多尺寸) | 安装包、桌面快捷方式、任务栏 |
| `icon.png` | PNG | 512x512 | 窗口图标、关于对话框 |

### 可选文件

| 文件名 | 格式 | 尺寸 | 用途 |
|--------|------|------|------|
| `installerHeader.bmp` | BMP | 150x57 | 安装程序顶部横幅 |
| `installerSidebar.bmp` | BMP | 164x314 | 安装程序侧边栏 |

## 快速生成图标

### 使用在线工具

1. 访问 https://www.icoconverter.com/
2. 上传你的 PNG 图标 (建议 512x512 像素)
3. 选择包含的尺寸 (16, 32, 48, 64, 128, 256)
4. 下载生成的 .ico 文件

### 使用命令行 (ImageMagick)

```bash
# 安装 ImageMagick 后执行
magick convert icon-512.png -define icon:auto-resize=256,128,64,48,32,16 icon.ico
```

## 设计建议

- 背景: 透明或与主题色一致
- 主色: #3b82f6 (蓝色) / #06b6d4 (青色)
- 风格: 简洁、现代、易于识别
- 小尺寸下仍需清晰可辨
